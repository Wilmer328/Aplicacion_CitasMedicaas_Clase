# Citas Médicas — Práctica TDD

Instrucciones rápidas para empezar (Windows):

1. Instalar dependencias:

```bash
npm install
```

2. Ejecutar tests:

```bash
npm test
```

3. Inicializar git local y crear el primer commit:

```bash
git init
git add .
git commit -m "chore: add project skeleton, requirements and initial tests"
```

4. Para vincular a GitHub (ejemplo):

```bash
# crea un repo vacío en GitHub y copia la URL, por ejemplo:
git remote add origin https://github.com/USUARIO/REPO.git
git branch -M main
git push -u origin main
```

Si tu GitHub requiere autenticación con token, usa un helper o credential manager.
